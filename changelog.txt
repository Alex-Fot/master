=== Custom Service Calculator — Changelog ===

== 9.1 ==
* Quick Menu: адаптивное быстрое меню «⋮» вверху страниц плагина (калькулятор, личный кабинет, регистрация мастера). При активации контур растягивается вправо/влево (в свободную от края сторону) и показывает два значка: «человечек с гаечным ключом» — Стать мастером, «человечек» — Личный кабинет; подсказки при наведении (tooltip + title).
* Quick Menu: стили наследуют выбранную пользователем тему ([data-theme="dark"] / светлая), CSS-переменные контейнеров плагина.
* Quick Menu: удержание значка «⋮» (≥300 мс) позволяет перемещать плашку по горизонтали на всю ширину экрана; позиция сохраняется в localStorage и восстанавливается при повторном входе (общая для домена).
* Quick Menu (логика разделов): раздел, на котором находится посетитель, неактивен — его значок подменяется иконкой калькулятора со ссылкой «Рассчитать услугу» (подмена выполняется на сервере PHP; JS добавляет aria-атрибуты и защиту от перезагрузки текущей страницы).
* Layout: к .csc-registration-page и #csc-cabinet добавлен position:relative — якорь для абсолютного позиционирования меню (у #csc-calculator уже был).
* Version: CSC_PLUGIN_VERSION 9.0.1 → 9.1 (bump сбрасывает кэш корневого csc-sw.js на CDN).

== 9.0.1 ==
* Web Push (CRITICAL): шифрование payload приведено к канону RFC 8291/8188 — info-строка "WebPush: info\0" + UAPublicKey||ASPublicKey, salt через HKDF-SHA256, padding до record_size; раньше браузеры не могли расшифровать сообщения (нестандартный секрет "WebPush-AESGCM\0"). Roundtrip проверен против Python-эталона http_ece (движок pywebpush).
* Web Push (HIGH): исправлен вызов openssl_pkey_derive() — лишний 4-й аргумент приводил к TypeError на PHP 8 при первой же отправке push.
* Routing: csc_check_routing_timeouts() добавлена ветка по routing_started_at для заявок без offer_time; такие зависшие заявки помечаются routing_status='timeout_global' / статусом routing_timeout с очисткой current_candidate вместо вечного «Ожидает».
* Master dashboard (PHP): из выдачи исключены заказы, где мастер уже в rejected_by, и заказы с истёкшим оффером, где мастер больше не current_candidate.
* Master dashboard (JS): mapStatus() больше не маппит routing_timeout/no_masters/истёкшие офферы в «waiting»; карточка скрывается при getOfferRemainingSec()==0 и если мастер не текущий кандидат.
* Master dashboard (security): после успешного входа токены token/open_order стираются из URL (history.replaceState) — повторный клик по тому же push не вызывает 403 на одноразовом токене.
* Admin «Управление заявками»: фильтры перевёрстаны в группы с подписями (статус/мастер), устранено наложение колонок «Статус» и «Действия» (min-width + flex-wrap), добавлена явная кнопка «🔄 Перезапустить поиск» для pending/searching/no_masters/routing_timeout, PHP-константы в инлайновом JS заменены литеральными строками (раньше ReferenceError ломал обработчик).
* Cabinet (клиент): клик по push автоматически подставляет телефон (csc_phone из URL) и номер заявки и выполняет вход; параметры очищаются из адресной строки. Убран спам-push «📋 Заявка #N» по каждому заказу при каждой загрузке ЛК.
* Service Worker: точное сравнение origin+pathname+search вместо client.url.includes(); фолбэк showNotification при openWindow===null; убран renotify (мигание дублей); убран optional-chaining для старых Safari; корневая копия csc-sw.js синхронизирована.
* Uninstall: в списке чистки cron заменён несуществующий хук на реальный csc_tg_webhook_selfcheck_hourly.
* Version: CSC_PLUGIN_VERSION 9.0 → 9.0.1 (bump сбрасывает кэш корневого csc-sw.js на CDN).

== 9.0 ==
* Geocoding (Nominatim/OSM): приведён к единому значению User-Agent (csc_nominatim_user_agent(): версия плагина + контактный e-mail администратора); добавлен централизованный троттлинг csc_nominatim_throttle() с гарантированной задержкой >= 1 секунды между всеми запросами к Nominatim (search и reverse), включая разные точки вызова в рамках одного процесса. Убраны ручные usleep-паузы; сохранена обработка HTTP 429.
* Security (личные кабинеты): токены доступа клиентов и мастеров хранятся в БД только как SHA-256 хэши (csc_hash_token / csc_verify_token) с ленивой миграцией ранее сохранённых открытых значений при первой сверке.
* Security: одноразовые входные креденшелы для ссылок входа в кабинет мастера (csc_issue_master_login_token) вместо постоянных токенов в URL; сессионный токен живёт 1 час; секреты убраны из адресной строки, передаются через заголовок X-CSC-Token.
* Security: подключены rate-limit подбора токенов входа — для клиента (AJAX-хендлеры) и для мастера (до 10 попыток / 15 минут, ответ HTTP 429); неудачные попытки фиксируются, успешный вход сбрасывает счётчик.
* Security: устранены мёртвые ветки авторизации и двойные hash_equals-проверки; исправлена проверка токена в REST-авторизации и платёжных модулях (сверка через csc_verify_token с поддержкой legacy).
* Admin (зависшие заказы): ручная отмена и перевод заказов со статусом «Ожидает оплаты» из страницы «Заявки (CSC)» (пока платежи заморожены); защита от отмены уже оплаченных заказов; фильтр зависимых платежей; массовые операции поддерживают эти статусы; при ручной отмене статус связанного платежа устанавливается в unpaid, чтобы крон-проверка не реактивировал.
* Admin: исправлена фатальная опечатка в логировании админ-уведомления о действиях с заявками; при ручном переводе в «Ожидает оплаты» фиксируется awaiting_payment_since.
* i18n: строки интерфейса PHP обёрнуты в __()/_e()/esc_html__()/esc_attr__()/_n() с доменом 'csc'; подписи статусов в JS локализуются через карту csc_status_labels_js(), передаваемую в CSC_MASTER_CONFIG.statusLabels; исправлены битые вызовы перевода.
* i18n: починен экстрактор languages-шаблона tools/i18n/make-pot.php (корректный разбор аргументов функций перевода с учётом вложенных скобок; защита от перезаписи пустым каталогом); перегенерированы languages/csc.pot (77 единственных + 4 плюральных записей) и синхронизирован languages/csc-ru_RU.po.
* Fixes: устранена логическая ошибка вычисления is_active в csc-ajax-handlers.php; удалены неиспользуемые пути авторизации; токены больше не подставляются в file-proxy URL и e-mail-ссылки модерации/рассылок.
* Docs: добавлены readme.txt, LICENSE (GPL v2) и changelog.txt.
