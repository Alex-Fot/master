Веб-приложение для расчёта и бронирования услуг: калькулятор с плиточным выбором разделов, личные кабинеты клиентов и мастеров, маршрутизация заявок, платежи, уведомления.

== Description ==

Custom Service Calculator (CSC) — это плагин WordPress для компаний и сервисных команд, которые принимают заявки на услуги с расчётом стоимости. Он превращает сайт в полноценную систему приёма и обработки заказов.

Основные возможности:

* **Калькулятор услуг** — плитка разделов, выбор услуг и опций, расчёт стоимости «на лету», оформление заявки прямо на странице.
* **Личный кабинет клиента** — вход по номеру телефона, история и статусы заявок, отмена и повтор заказа.
* **Кабинет мастера** — входящие заявки, принятие/отказ, обновление статусов, загрузка фото выполненных работ, уведомления в реальном времени (push), рейтинг и отзывы.
* **Маршрутизация заявок** — распределение между мастерами по городам/специализациям, таймауты и резервная очередь.
* **Платежи** — интеграция платёжных провайдеров (расширяемый интерфейс), вебхуки, проверка статуса оплаты по крону; финансовый учёт (транзакции, ledger, счета).
* **Админка** — управление разделами, услугами, сотрудниками, заявками, скидками, городами; аналитика; импорт/экспорт; отзывы; бэкапы.
* **Уведомления** — e-mail, Telegram-бот, push (Web Push), напоминания о статусе заявки.
* **Геокодер** — определение адреса через OpenStreetMap Nominatim (с соблюдением лимитов OSM Usage Policy: единый User-Agent и задержка ≥1 сек между запросами).

Безопасность:

* Токены доступа к кабинетам хранятся в БД только в виде SHA-256 хэшей (с ленивой миграцией открытых значений).
* Вход по токену защищён rate-limit от подбора (лимитеры попыток для клиентов и мастеров, окно 15 минут).
* Одноразовые креденшелы для ссылок входа вместо постоянных токенов в URL; секреты не светятся в адресной строке (заголовок X-CSC-Token).
* Nonce-проверки всех AJAX/REST-действий, capability-контроль административных операций.

Локализация:

* Текстовый домен: `csc` (`/languages`).
* Поставляется русский перевод (`csc-ru_RU.po`); шаблон `csc.pot` для перевода на другие языки.

== Installation ==

1. Загрузите папку `custom-service-calculator` в директорию `/wp-content/plugins/`.
2. Активируйте плагин через меню «Плагины» в WordPress.
3. При активации автоматически создаются таблицы `{prefix}csc_orders`, `{prefix}csc_order_history`, `{prefix}csc_notifications` и финансовые таблицы; колонки достраиваются миграциями при обновлении.
4. Откройте «Настройки → Калькулятор услуг» и настройте разделы и услуги («Разделы (CSC)», «Услуги (CSC)»).
5. Добавьте шорткод `[service_calculator]` на страницу калькулятора.
6. При необходимости добавьте `[csc_personal_cabinet]` (личный кабинет клиента) и `[csc_become_master]` (анкета мастера).

== Frequently Asked Questions ==

= Какие шорткоды доступны? =

`[service_calculator]` — калькулятор и оформление заявки; `[csc_personal_cabinet]` — личный кабинет клиента; `[csc_become_master]` — форма регистрации мастера.

= Как войти в личный кабинет клиента? =

По номеру телефона: на странице кабинета клиент вводит телефон и получает доступ к истории своих заявок. Неудачные попытки ограничены rate-limiter'ом.

= Где хранятся токены доступа? =

Только в виде SHA-256 хэшей в таблице мастеров/опциях плагина. Ссылки входа содержат одноразовый креденшел с коротким временем жизни; постоянный токен в URL не передаётся.

= Можно ли отменить «зависшую» заявку со статусом «Ожидает оплаты»? =

Да. В админке («Заявки (CSC)») для таких заказов доступны ручная отмена и перевод между статусами; при отмене связанный платёж помечается как неоплаченный и не будет повторно активирован кроном.

= Какие внешние сервисы используются? =

OpenStreetMap Nominatim (геокодинг, лимит 1 запрос/сек), Telegram Bot API (уведомления), Web Push (VAPID), платёжные провайдеры (подключаются отдельно).

= Что происходит при удалении плагина? =

`uninstall.php` удаляет все таблицы, опции (`csc_*`), транзиенты и крон-задачи плагина. Для сохранения данных сделайте бэкап заранее («Настройки → Импорт/Экспорт»).
